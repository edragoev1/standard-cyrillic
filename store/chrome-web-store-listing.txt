STORE LISTING TAB

Name (from the manifest):
Standard Cyrillic

Summary (from the manifest, 132 characters at most):
Shows Bulgarian text in the standard Cyrillic letter shapes: т, д, г, и, п as in print, not as m, g, s, u, n.

Category:   Accessibility
Language:   English as the default; add Bulgarian as a second language
            with the Bulgarian text below.

Description, English:

Read Bulgarian websites in the letters you learned to read.

Many Bulgarian websites now draw т like an m, д like a g, г like an s
turned around, и like a u and п like an n: the shapes of handwriting,
used in print. Standard Cyrillic puts back the standard letter shapes,
the ones in books, in Russian and in most Cyrillic print.

How it works:
• Fonts that switch to these shapes for Bulgarian text are switched back.
• Fonts that draw these shapes always, as some newspapers' own fonts do,
  get their Cyrillic letters from IBM Plex Sans or IBM Plex Serif instead,
  in the same weight and size. Latin letters, numbers and icons stay as
  the site draws them.

It is on for every site. The button in the toolbar turns it off for a
site, and shows which fonts it replaced there.

Private: it collects nothing and sends nothing anywhere. It has no
account, no tracking and no ads.

Free, under the MIT License. IBM Plex is under the SIL Open Font License.

Работи на всички сайтове. Бутонът в лентата с инструменти го изключва за
даден сайт и показва кои шрифтове е заменил там.

Поверително: не събира и не изпраща никакви данни. Без регистрация, без

Безплатно, под лиценза MIT. IBM Plex е под лиценза SIL Open Font License.

PRIVACY PRACTICES TAB
---------------------

Single purpose:
Shows Bulgarian text on web pages in the standard Cyrillic letter shapes
instead of the handwritten shapes some fonts use.

Permission justification:
• storage: remembers the sites where the user turned the extension off.
• activeTab: lets the toolbar popup read the address of the current tab,
  to show and change the setting for that site.
• Host permission (content script on http and https pages): to change the
  letter shapes, the extension must run on the pages the user reads; it
  only adds a style and font faces to the page, and reads nothing from it
  but the fonts the page uses.

Remote code: No. All code and fonts are in the package.

Data usage: check none of the data types. Certify that the extension does
not sell or transfer user data, does not use it for unrelated purposes,
and does not use it for creditworthiness or lending.

Privacy policy URL: not required when no user data is collected. If the
form insists, a one-line page will do: "Standard Cyrillic collects no
data and sends nothing anywhere."
